# Gait CNN · Recorded Playback

This replaces the original Stage 1 `dashboard.py` with a recorded-playback view. After loading a trusted `.pt` checkpoint and compatible `..._Name_labeled.csv`, the CNN runs **dense inference** across the recording once and caches it. The playback cursor advances approximately every second and chooses the corresponding saved prediction. A green shaded region shows which **148-sample input window** generated that prediction. This is *offline replay*, not live sensor capture.

## Windows Command Prompt setup

```cmd
cd C:\Users\rrbhat\Documents\Gait-Estimation
gait-cnn\Scripts\activate.bat
python -m pip install -r gait_dashboard_playback\requirements-dashboard.txt
python -m streamlit run gait_dashboard_playback\dashboard.py
```

If you extract the ZIP to a different folder, change the relative path. Or `cd` into the extracted `gait_dashboard_playback` folder and run `python -m streamlit run dashboard.py`.

## Usage

1. Upload a `.pt` checkpoint generated by `train_imu_configurable.py` (contains model weights, ordered features, mean/std).
2. Upload a CSV containing the required feature columns. `L_stance`, `R_stance` are optional reference labels.
3. Click **Play**. The cursor advances by roughly 1 second per second, updating the bilateral states and charts. Pause, restart, or move the seek slider. The IMU graph highlights the exact input window and allows choosing a channel.
4. Whole-recording metrics and CSV export are shown below playback.

The model's window is **148 samples** (about 1 second at 148.15 Hz); playback displays predictions **~1 second apart**. The underlying inference processes each valid row (stride 1) before replay. If a gap occurs in valid IMU windows, the recording skips that gap. This is bilateral stance/swing classification, *not* continuous gait-cycle percentage regression.

When displaying FSR-derived accuracy, use a checkpoint from a fold that **did not train on the uploaded participant**. Load only trusted checkpoints. Derived cadence and stride timing can be noisy without validated event smoothing. Stride length is not computed because a single binary gait-state prediction is insufficient to infer walking distance.

## Package files

- `dashboard.py`: updated Streamlit playback interface
- `gait_dashboard_core.py`: original CNN architecture, checkpoint loading, dense inference and metrics
- `requirements-dashboard.txt`: dependency list
- `run_dashboard.bat`: convenience launcher when run from this directory with the environment activated
